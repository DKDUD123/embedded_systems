# Embedded Systems

라즈베리파이 4(Raspberry Pi 4)를 활용한 임베디드 시스템 실습 프로젝트입니다.

## 개발 환경

- Device: Raspberry Pi 4
- OS: Raspberry Pi OS
- Language: Python
- Version Control: Git & GitHub

## 프로젝트 구성

```text
embedded_systems/
├── week10/
│   ├── save_sensor_data.py
│   ├── csv_to_sqlite.py
│   ├── query_sqlite.py
│   ├── make_report.py
│   ├── environment.csv
│   └── daily_export.csv
├── .gitignore
└── README.md
```

## 실습 내용

### Week 10 - 센서 데이터 저장 및 데이터베이스 관리

- 센서 데이터 CSV 파일 저장
- CSV 데이터를 SQLite 데이터베이스로 변환
- SQLite 데이터 조회
- 센서 데이터 보고서 생성

## GitHub 관리

Git을 이용하여 프로젝트 코드와 변경 이력을 관리합니다.
